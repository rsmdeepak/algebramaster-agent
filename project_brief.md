# My agent: AlgebraMaster 8th Grade Math Agent
One-liner: A stateful AI math tutor that helps 8th-grade students learn algebra with practice problems, step-by-step guidance, interactive topic cards, and code execution.

Tool coverage:
- Memory: Student learning profile, target algebra topics (linear equations, slope, inequalities), past quiz scores, and mastered skills.
- Tools: Practice problem generator, step-by-step answer validator, and algebra formula/rule lookup.
- Catalog/UI: Topic catalog, formula cheat sheets, and student progress scorecards rendered as A2UI cards.
- Image gen: Visual problem cards, coordinate plane graph representations, and achievement reward badges.
- Sandbox: Python code execution for verifying algebraic equation solving, calculating values, and graph plotting.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: Python Code Sandbox for symbolic equation verification and mathematical calculations.
